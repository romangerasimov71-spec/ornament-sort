# Ornament Sort / Новогодняя сортировка

HTML5 sorting puzzle: glass ornaments in gift boxes, 85 levels. Plain JS + canvas, Playgama Bridge SDK.
Open `index.html` from any static web server. Prototype: `prototype/index.html`.
Rules for the game: `CLAUDE.md`, owner's decisions: `docs/decisions.md`, audio credits: `CREDITS.md`, tests: `tests/README.md`.
