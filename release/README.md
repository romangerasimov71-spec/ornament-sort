## Как собрать все архивы
```
node tools/build-platform.js
```
Архивы лягут в `dist/platforms/<площадка>/ornament-sort-<площадка>.zip`, в git их нет. Рядом с каждым README лежит `BUILD-SHA256.txt`: контрольная сумма и коммит, из которого собрано. Скрипт сначала запускает `tools/build-release.js` (он сам проверяет, что в игре нет localStorage, внешних ссылок и русских имён файлов).

Сейчас все четыре архива одинаковые: Playgama Bridge внутри игры сам определяет площадку (ВК, ОК, Яндекс, Playgama) и подключает её SDK. Если площадке понадобится свой конфиг, кладём `release/<площадка>/bridge-config.patch.json`, скрипт подмешает его только в её архив.

## Как перерисовать картинки
Сцены снимает Playwright из самой игры, потом собирает Pillow (в `release/_src/`; сырые снимки в `release/_src/raw/` в git не лежат):
```
python3 -m http.server 8765 &
NODE_PATH=/opt/node-tools/node_modules node release/_src/capture.js
NODE_PATH=/opt/node-tools/node_modules node release/_src/capture-art.js
python3 release/_src/compose.py
```
Картинки нарисованы из игры, Higgsfield и ИИ-картинки не использовались, эмодзи нет.

## Что не проверено
- Яндекс: размеры и лимиты по памяти (сеть не пускает на yandex.ru).
- ВК и ОК: правила взяты из навыка студии, настоящих страниц ВК/ОК в этой сессии не читал; игру внутри ВК и ОК не запускал.
- Размеры иконок ОК (128/256) по памяти.
- Скриншоты снимали на русской и английской локали по настройке браузера, а не через настоящий `bridge.platform.language`.
