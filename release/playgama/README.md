# Playgama: пакет к выкладке

Тестовая ссылка игры (GitHub Pages): https://romangerasimov71-spec.github.io/ornament-sort/

## Что лежит в папке
- `texts.md` — все поля формы на английском: название, описание, как играть, история, категория `matching`, языки, устройства.
- `assets/icon-800x800.png` — иконка.
- `assets/cover-landscape-1920x1080-en.png` и `-ru` — альбомная обложка.
- `assets/cover-portrait-1080x1920-en.png` и `-ru` — книжная обложка.
- `assets/screenshots/` — по 5 сцен (обучение, середина, поздний уровень, победа, окно уровней): альбом 1920×1080 и портрет 1080×1920, на EN и RU, JPG.
- `BUILD-SHA256.txt` — контрольная сумма архива и коммит, из которого он собран.

## Как собрать архив
```
node tools/build-platform.js playgama
```
Результат: `dist/platforms/playgama/ornament-sort-playgama.zip` (в git не кладём). `index.html` лежит в корне архива, в нём `playgama-bridge-config.json`. Сборка Playgama — это основной архив игры без изменений: Bridge SDK и конфиг уже в нём, язык игра берёт из `bridge.platform.language`, сохранение идёт только через `bridge.storage`.

- Вход в консоль Playgama (токен коннектора уже подключён; если инструменты вернут ошибку входа, он входит во встроенном браузере).
- **Загрузить скриншоты в консоли**: инструмента для этого нет. Файлы лежат в `assets/screenshots/`. Нужны альбомные и книжные, лучше EN.
- Пройти сертификацию в QA Tool (кнопки «Yes», «Granted / Not granted»; могу вести по шагам).
- **Опубликовать пост** со ссылкой на игру, если запускаем продвижение (пост публикует Роман, я готовлю текст и жду ссылку на пост).
- **Отправить игру на модерацию** в консоли (кнопку нажимает только он).
- Решить про `distributeEverywhere` (разослать игру по партнёрам: Яндекс, YouTube, MSN и другим). По навыку студии включаем.

## Необратимое: нужно отдельное «да» Романа
- `publish_sandbox` — публичная страница без модерации.
- `start_sandbox_traffic` — тратит один из 2 бесплатных запусков продвижения (дальше платно).
- `send_playgama_catalog_update` — если игра уже в каталоге, обновляет её у всех игроков.
- Отправка на модерацию — делает сам Роман.

## Требования Playgama: что известно
Правила прочитаны вживую (`get_game_checklist`, 7 страниц, `get_bridge_sdk_docs api`). Самые частые причины отказа и как у нас:
- 3.2.1 хранение только через Bridge: сборка проверяет, что в коде нет localStorage.
- 1.2.4 внешняя аналитика запрещена, разрешена аналитика Bridge: сборщик добавляет `js/analytics.js` через Bridge (см. `docs/analytics.md` игры после его коммита).
- 3.3.2 звук только настоящие файлы: так и есть (CC0, `CREDITS.md`).
- 3.5.1 название: «Ornament Sort» в EN-форме, «Новогодняя сортировка» в игре на русском. Правило требует совпадения названия в игре и в заявке: заявку делаем на английском, а английский заголовок в игре «Ornament Sort».
- Не проверено мной (должны подтвердить проверяющие): 1.6 (квадратное окно, любой размер), 1.7 (стабильность), 2.1–2.2 (все случаи рекламы), 3.3.4–3.3.5 (звук при паузе и скрытии вкладки).
- Размер архива и платформенные требования: MSN до 50 МБ, YouTube до 30 МБ и без внешних вызовов — архив игры существенно меньше (точный размер в `BUILD-SHA256.txt`). Оговорка: Bridge сам подтягивает SDK площадки только на этой площадке.
