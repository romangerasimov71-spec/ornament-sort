# Одноклассники: пакет к выкладке

Тестовая ссылка игры: https://romangerasimov71-spec.github.io/ornament-sort/

## Что лежит в папке
- `texts.md` — тексты и отличия от ВК.
- `assets/icon-128x128.png`, `assets/icon-256x256.png` — иконки (размеры по памяти).
- `BUILD-SHA256.txt` — контрольная сумма архива.
- Остальные картинки (иконка 576, сниппет, скриншоты) берём из `release/vk/assets/`.

## Как собрать архив
```
node tools/build-platform.js ok
```
Результат: `dist/platforms/ok/ornament-sort-ok.zip`. **Чем отличается:** ничем по файлам. Игра в ОК идёт той же сборкой, что и в ВК: заявка подаётся в кабинете ВК («Другие площадки» → «Опубликовать» напротив ОК) и использует ту же заливку на хостинг VK. Bridge определяет ОК по адресу страницы (`api_server`, `apiconnection`) и подключает FAPI ОК сам. Отдельный архив ОК нужен только если понадобится своя настройка конфига (`release/ok/bridge-config.patch.json`).

## Что сделаю я (Claude), по шагам
1. После того как в dev.vk.ru готова игра (шаги из `release/vk/README.md`), нажму «Опубликовать» напротив ОК и подтвержу соглашение ОК (нужно «да» Романа).
2. Если появится «OK API Error» — обновлю страницу; если стоит «ID профиля», привязка есть.
3. Проверю в песочнице ОК: сохранение, пауза при потере фокуса (ViewHide в ОК нет, Bridge использует `visibilitychange`), реклама, нет внешних ссылок.
4. Подам общую заявку (ВК и ОК) только после «да» Романа.

## Что нужно от Романа
- Принять соглашение ОК (одна кнопка, я подготовлю, но подтверждение его).
- Те же входы, что для ВК.

## Необратимое: нужно отдельное «да» Романа
- «Опубликовать» напротив ОК.
- Подача заявки на модерацию.
- Включение рекламы.

## Что известно / не проверено
Правила ОК взяты из навыка `vk-games-publish`: в ОК нет ViewHide, ShowWallPostBox, AddToFavorites, ShowLeaderBoardBox, внешние ссылки запрещены, сохранения раздельные для ВК и ОК. Нашей игре это не мешает (ничего из перечисленного она не использует). Размеры иконок ОК и лимиты текстов взяты по памяти, сверить с кабинетом. Игра в настоящем ОК не проверялась.
