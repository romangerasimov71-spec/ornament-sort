# Одноклассники: тексты карточки

Заявка в ОК идёт вместе с VK (кабинет dev.vk.ru → «Другие площадки» → ОК), тексты и картинки берутся оттуда. Поэтому для ОК используются тексты и картинки из `release/vk/`. Ниже только то, что отличается.

Название: **Новогодняя сортировка** (как в игре).

## Краткое описание
```
Разложи ёлочные шары по коробкам: уютная новогодняя головоломка, 85 уровней.
```

## Описание
Тот же текст, что для ВК (`release/vk/texts.md`). Лимиты ОК кабинет покажет сам; если не помещается, короткая версия:
```
Нажимай на коробки и раскладывай ёлочные шары по цветам: в каждой коробке должен остаться один цвет. 85 уровней, от разминки до настоящих задачек. У каждого цвета свой узор, прогресс сохраняется, играть можно на телефоне и компьютере. Спокойная новогодняя головоломка без таймеров.
```

## Возраст / жанр
0+, Головоломки.

## Что в игре отличается для ОК
- Бонус за рекламу («+1 пустая коробка») работает через Bridge так же, как в ВК; отдельный код не нужен.
- Покупок, приглашений, публикаций на стену, «в избранное» и ссылок наружу в игре нет: из того, что в ОК запрещено или не работает (ViewHide, ShowWallPostBox, внешние ссылки), в игре не используется ничего. Это нужно проверить в песочнице ОК перед подачей.

## Файлы (папка `assets/`)
`icon-128x128.png`, `icon-256x256.png` (размеры по памяти, сверить с кабинетом). Остальное (иконка 576, сниппет, скриншоты 600×1200) — из `release/vk/assets/`.
