# Яндекс Игры: черновик (требования взяты по памяти, сверить)

Сеть здесь не пускает на yandex.ru, поэтому размеры и лимиты ниже **не проверены по актуальной документации**.

Название (как в игре): **Новогодняя сортировка**; английское: **Ornament Sort**.

## Короткое описание (RU)
```
Уютная новогодняя головоломка: раскладывай ёлочные шары по коробкам, чтобы в каждой остался один цвет. 85 уровней.
```

## Описание (RU)
```
Нажми на коробку, чтобы взять верхний шар (или всю верхнюю группу шаров одного цвета), и нажми на другую коробку, чтобы положить его. Класть можно на шар того же цвета или в пустую коробку. Когда в каждой коробке один цвет, уровень пройден.

85 уровней: от разминки до настоящих задачек. Больше цветов, меньше свободных коробок. У каждого цвета свой узор, поэтому шары легко отличать. За уровень даётся до трёх звёзд, можно отменить ход или начать уровень заново. Если застрял, можно по желанию посмотреть рекламу и получить дополнительную пустую коробку. Прогресс сохраняется. Играть можно на телефоне и компьютере.
```

## Description (EN)
```
Tap a box to lift the top ornament (or the whole top group of one color), then tap another box to drop it there. You can place ornaments only on the same color or into an empty box. Make every box hold one color to win.

85 levels, from a gentle warm-up to real brain teasers. More colors, less free room. Each color has its own pattern, so the ornaments are easy to tell apart. Earn up to three stars per level, undo a move or restart. If you get stuck, you may watch an optional ad for one extra empty box. Progress is saved. Works on phones and desktop.
```

## Как играть (RU)
```
Нажми на коробку, потом на другую: шар переедет туда, если сверху такой же цвет или коробка пустая. Собери в каждой коробке один цвет.
```

## Категории / возраст
Головоломки (основная), Казуальные. Возраст 0+.

## Что нужно знать про Яндекс
- Яндекс Игры требуют русский язык: он есть. Язык берётся из Bridge (`platform.language`), как требует и Playgama.
- Яндекс умеет сам подставлять свой SDK, Bridge определяет Яндекс по адресу страницы и сам подключает его. Отдельная сборка не нужна.
- Регистрация новых разработчиков в Яндекс Играх по навыку студии закрыта (записано в `vk-games-publish`). Если аккаунта нет, остаётся вариант «Playgama сама разошлёт» (галка `distributeEverywhere`).
- Игра полностью офлайн внутри архива, внешних ссылок нет, Esc не используется.
