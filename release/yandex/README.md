# Яндекс Игры: пакет к выкладке

Тестовая ссылка игры: https://romangerasimov71-spec.github.io/ornament-sort/

## Что лежит в папке
- `texts.md` — тексты RU/EN, как играть, категории, возраст.
- `assets/icon-512x512.png` — иконка.
- `assets/cover-800x470-ru.png`, `-en` — обложка.
- `assets/screenshots/` — альбом 1280×720 и портрет 720×1280, RU и EN, 4 сцены.
- `BUILD-SHA256.txt` — контрольная сумма архива.

**Все размеры и лимиты Яндекса взяты по памяти: страница документации недоступна из этой сессии (сеть не пускает на yandex.ru). Перед загрузкой их надо сверить в консоли Яндекс Игр.**

## Как собрать архив
```
node tools/build-platform.js yandex
```
Результат: `dist/platforms/yandex/ornament-sort-yandex.zip`. **Чем отличается:** по файлам ничем. Bridge определяет Яндекс по адресу и сам подключает его SDK. Отдельный патч конфига (`yandex.useSignedData` и подобное) пока не нужен.

## Что сделаю я (Claude), по шагам
1. Соберу архив. Яндекс принимает загрузку только в консоли разработчика, у меня туда доступа нет.
2. Заполню черновик по `texts.md`, если Роман войдёт в консоль во встроенном браузере и даст добавить игру.
3. Загрузку архива и отправку на модерацию делаю только после «да».
